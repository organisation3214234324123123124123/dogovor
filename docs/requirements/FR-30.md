# FR-30. Письмо CONFIRM_REQUEST с персональной ссылкой

Приоритет: **Must** · Этап: **1** · Модуль: подтверждение по ссылке

## Требование (SRS v3)
Каждый исполнитель с пунктами в pending получает письмо CONFIRM_REQUEST с персональной ссылкой.

## Критерии приёмки
1. После «Разослать» у исполнителя с пунктом в `pending` есть строка `notifications` типа CONFIRM_REQUEST; письмо уходит не позже 5 минут (AC-3.1).
2. Письмо содержит пункт, встречу и кнопки «Принимаю», «Нужен другой срок», «Это не моё».
3. На пару (человек, встреча) одна действующая ссылка в `access_links`; у двух пунктов одного исполнителя одна ссылка. Если действующая (не отозванная) ссылка уже истекла, сервис сначала отзывает её (`revoked_at`), потом выдаёт новую — иначе мешает UNIQUE на действующую ссылку.
4. Токен — 32 байта из криптостойкого генератора, base64url; в базе только SHA-256 (`token_hash bytea(32)`, UNIQUE); сравнение за постоянное время.
5. `expires_at` = большее из: выдача + 14 дней, позднейший срок открытых пунктов получателя по встрече + 30 дней (BR-18).
6. Пункт, согласованный на встрече (`accepted`), CONFIRM_REQUEST не получает (только SUMMARY со ссылкой, FR-35).
7. Пункт без исполнителя ссылки и письма не получает (BR-4).
8. «Переназначить» → новый исполнитель получает ссылку и CONFIRM_REQUEST (FR-43).
9. Пункт, добавленный после рассылки, уходит отдельным CONFIRM_REQUEST (BR-5).
10. Повторное «Разослать» не создаёт второго письма (dedupe_key `{item_id}:CONFIRM_REQUEST:{person_id}:{version}`, [BR.md](BR.md#dedupe_key-br-5)).
11. Токен не пишется в логи (NFR-13).

## Правила и данные
- Письмо: From «{Имя ведущего} через Договорились», Reply-To — адрес ведущего; HTML и text/plain с теми же ссылками; без вложений.
- **BR-11.** Не больше 3 писем одному человеку в неделю от одной серии (кроме HOST_RESPONSE ведущему). Лишние объединяются в одно письмо на следующий рабочий день.
- **BR-17.** Временная ошибка почты (4xx, таймаут) — до 3 повторов через 5, 15 и 60 минут; постоянная (5xx) — failed сразу.
- SUMMARY и CONFIRM_REQUEST одновременно одному человеку — OQ-04.
