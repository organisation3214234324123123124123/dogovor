# FR-09. Архивирование серии, исключение участника

Приоритет: **Should** · Этап: **2** (этап в SRS расходится — вопрос аналитикам А-2) · Модуль: аккаунт и серии

## Требование (SRS v3)
Архивирование серии. Исключение участника из состава не трогает его пункты.

## Критерии приёмки
1. `POST /series/{id}/archive` → `series.status = archived`.
2. В архивной серии «Начать встречу» → 409 `SERIES_ARCHIVED`.
3. `GET /series` по умолчанию показывает статус серии; архивная серия остаётся доступной для чтения.
4. `DELETE /series/{id}/members/{personId}` → человек исключён из `series_members`; его пункты (`assignee_person_id`, статус, сроки) не меняются.
5. Исключённого человека нельзя назначить исполнителем новых пунктов → 422 `NOT_A_PARTICIPANT` (BR-1).
6. Серия другого ведущего → 404 `NOT_FOUND`.

## Правила и данные
- **BR-20 (фрагмент).** Пункты, комментарии и участники хранятся, пока серия активна, и 1 год после архивации. Чистку запускает ежедневная задача Celery Beat.
- `series.status enum(active, archived)`.
