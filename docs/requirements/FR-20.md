# FR-20. Пробелы по правилам

Приоритет: **Must** · Этап: **1** · Модуль: пробелы и закрытие

## Требование (SRS v3)
Пробелы по правилам пересчитываются при каждом изменении пункта. Правила срабатывают синхронно за доли секунды, LLM — асинхронно и только дополняет их. Если модель не ответила за 8 секунд или недоступна, панель работает на правилах.

## Типы пробелов
| Тип | Условие | Вопрос по умолчанию |
| --- | --- | --- |
| `no_assignee` | Нет assignee_person_id | «Кто берёт это на себя?» |
| `no_due` | Нет ни due_date, ни due_text | «{Имя}, к какому числу?» |
| `due_vague` | Есть due_text, нет даты: «на днях», «как можно скорее», «потом» | ««На днях» — это к какому числу?» |
| `due_past` | due_date раньше сегодня (пояс серии) | «Этот срок уже прошёл — какой новый?» |
| `vague_action` | «Что» — процесс без результата: «разобраться», «проработать», «посмотреть», «подумать». Этап 1 — словарь глаголов | «Что будет результатом?» (на этапе 2 — вопрос от LLM, FR-21) |

## Критерии приёмки
1. Пункт без исполнителя и срока с what «Разобраться с выгрузкой» → открыты `no_assignee`, `no_due`, `vague_action` с `source = rule` (AC-1.1).
2. due_text «на днях» без даты → `due_vague`; due_date вчера → `due_past` (AC-1.2).
3. Ведущий ставит дату → `no_due` получает `resolved_at`, счётчик уменьшается не позже 1 с (AC-1.3).
4. Условие снова стало истинным после закрытия → открывается новый пробел (кроме отклонённого типа, FR-24).
5. Пересчёт идёт при каждом изменении пункта (создание, PATCH, разбор LLM).
6. Пробел появляется в панели не позже 500 мс после ввода строки, p95 (NFR-01).
7. Готовый вопрос не длиннее 120 символов.
8. При открытии пробела пишется `gap_detected` (type, source), при закрытии — `gap_resolved` (type, seconds_since_detected).
9. LLM недоступна → правила всё равно находят пробелы (AC-1.8).
10. Подсказки видит только ведущий; в письма они не попадают (AC-1.5).

## Правила и данные
- `gaps`: id, item_id, type, source enum(rule, llm), question varchar(300), detected_at, resolved_at, dismissed_at. Открытый пробел: resolved_at IS NULL AND dismissed_at IS NULL.
- **BR-2.** Если дату не удалось извлечь, исходная фраза хранится в due_text и даёт пробел due_vague.
- Подстановка {Имя} без исполнителя; один вопрос на пункт или на пробел — OQ-08, OQ-09.
