# FR-11. Разбор строки по правилам

Приоритет: **Must** · Этап: **1** · Модуль: панель встречи

## Требование (SRS v3)
Разбор по правилам: исполнитель — по имени из состава с учётом падежа (pymorphy3), срок — из выражений «до пятницы», «к 20.10», «завтра», «через неделю».

## Критерии приёмки
«Сегодня» = 2026-10-15 (четверг) по поясу серии; в составе Иван (p_12) и Анна (p_15).
1. «Иван разберётся с выгрузкой к пятнице» → assignee_person_id = p_12, due_date = 2026-10-16, due_text = «к пятнице».
2. «Поручили Ивану подготовить отчёт» и «с Анной согласовать договор» → исполнитель найден по косвенному падежу (p_12, p_15).
3. «Пётр сделает отчёт завтра», Петра нет в составе → assignee пусто, пробел `no_assignee`; due_date = 2026-10-16.
4. «… к 20.10» → due_date = 2026-10-20.
5. «… через неделю» → due_date = 2026-10-22.
6. «… до пятницы» → due_date = 2026-10-16.
7. «… на днях», «как можно скорее», «потом» → due_date пусто, due_text = исходная фраза, пробел `due_vague` (BR-2).
8. Строка без срока → due_date и due_text пусты, пробел `no_due`.
9. Поле из `manual_fields` (поправлено ведущим) повторный разбор не меняет.
10. Разбор работает без LLM и без сети (AC-1.8).

## Правила и данные
- **BR-1.** Исполнителем может быть только участник серии.
- **BR-2.** Срок — дата не раньше сегодняшней по поясу серии. Если дату не удалось извлечь, исходная фраза хранится в due_text и даёт пробел due_vague.
- Что пишется в `what` на этапе 1, тёзки, «к 20.10» в прошлом, «до пятницы» в пятницу — OQ-08.
