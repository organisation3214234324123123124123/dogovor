# FR-07. Присутствие на встрече

Приоритет: **Must** · Этап: **1** · Модуль: аккаунт и серии

## Требование (SRS v3)
Присутствие: по умолчанию присутствуют все участники серии, ведущий снимает отметку одним нажатием.

## Критерии приёмки
1. После «Начать встречу» у всех участников серии `meeting_participants.present = true`.
2. `PATCH /meetings/{id}` со снятием присутствия у человека → `present = false`; повторно → снова `true`.
3. Человек не из состава встречи → 422 `NOT_A_PARTICIPANT`.
4. Отметка присутствия влияет на «Согласовано на встрече»: у отсутствующего исполнителя действие недоступно (BR-3, FR-25).
5. Встреча другого ведущего → 404 `NOT_FOUND`.

## Правила и данные
- `meeting_participants`: meeting_id, person_id, present bool = true. PK(meeting_id, person_id).
- **BR-3.** «Согласовано на встрече» ставится, только если исполнитель присутствует, есть due_date и нет открытых пробелов no_assignee, no_due, due_vague, due_past.
