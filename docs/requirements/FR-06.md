# FR-06. Начать встречу

Приоритет: **Must** · Этап: **1** · Модуль: аккаунт и серии

## Требование (SRS v3)
«Начать встречу» создаёт встречу серии: `planned_start = сейчас`, `planned_end = planned_start + длительность`; ведущий может поправить конец.

## Критерии приёмки
1. `POST /series/{id}/meetings` в серии с длительностью 60 мин в 10:00 UTC → встреча с planned_start = 10:00, planned_end = 11:00, `started_at` заполнен.
2. Ответ содержит встречу и список для сверки (FR-42); пустой список, если открытых пунктов нет.
3. Создаются `meeting_participants` для всех участников серии с `present = true` (FR-07).
4. `PATCH /meetings/{id}` с новым planned_end → конец изменён.
5. В серии уже есть встреча в `live` или `closing` → вторую начать нельзя → 409 `MEETING_ALREADY_LIVE` (OQ-05).
6. Серия в `archived` → 409 `SERIES_ARCHIVED`.
7. Серия другого ведущего → 404 `NOT_FOUND`.
8. Пишется событие `meeting_started` с props `capture_mode`, `review_items_count`.

## Правила и данные
- `meetings`: id, series_id, planned_start, planned_end, status enum(planned, live, closing, sent), started_at, closure_opened_at, closure_trigger enum(button, timer), summary_sent_at, created_at. INDEX(series_id, planned_start DESC); в серии не больше одной встречи в live или closing.
- Какой статус у новой встречи и как идут переходы статусов встречи — OQ-05 (предложение: сразу `live`).
