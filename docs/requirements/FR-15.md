# FR-15. Удаление пункта в draft

Приоритет: **Must** · Этап: **1** · Модуль: панель встречи

## Требование (SRS v3)
Удаление пункта в draft.

## Критерии приёмки
1. `DELETE /items/{id}` у пункта в `draft` → 204; пункт и его пробелы (`gaps`) физически удалены.
2. Удаление пункта не в `draft` (pending, accepted, disputed, done, cancelled) → 409 `INVALID_TRANSITION` (FR-29: только «Снять»).
3. Пункт другого ведущего → 404 `NOT_FOUND`.
4. Панель видит удаление без перезагрузки (событие — OQ-07).

## Правила и данные
- Переход: `draft` → (нет) | «Удалить» | Ведущий | физическое удаление вместе с пробелами.
