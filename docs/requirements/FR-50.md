# FR-50. Запись событий аналитики

Приоритет: **Must** · Этап: **1** · Модуль: служебное

## Требование (SRS v3)
Запись событий аналитики. Событие пишется в analytics_events в той же транзакции, что и действие. Общие поля: name, created_at, user_id, series_id, meeting_id, item_id; в props — только типы, числа и флаги, без текста.

| Событие | Когда | props |
| --- | --- | --- |
| series_created | Создана серия | members_count, has_external |
| meeting_started | «Начать встречу» | capture_mode, review_items_count |
| review_action / review_skipped | Действие на сверке / сверка пропущена | action: done, reschedule, cancel, reassign |
| decision_captured | Добавлено решение | source: manual, asr; fields_filled |
| closure_opened | Открыт режим закрытия | trigger: button, timer; minutes_to_planned_end |
| gap_detected | Найден пробел | type, source: rule, llm |
| gap_resolved | Пробел закрыт | type, seconds_since_detected |
| gap_dismissed | «Не пробел» | type, source |
| overload_warning_shown | Предупреждение о загрузке (Should) | open_items |
| agenda_item_uncovered | Пункт повестки без решений (Should) | position; resolution: covered, moved |
| accepted_in_meeting | «Согласовано на встрече» | due_changed |
| summary_sent | «Разослать» | items_total, items_with_open_gaps, recipients |
| summary_copied | «Скопировать итог» | items_total; был ли до этого summary_sent |
| link_opened | Открыта страница по ссылке | notification_type |
| link_answered | Ответ по ссылке | answer: accept, reschedule, decline, done; hours_since_sent |
| reminder_sent | Ушло DUE_TOMORROW | — |
| item_done | Пункт сделан | on_time; by: assignee, host, tracker |
| item_overdue | Ежедневно в 00:05 по поясу серии | days_overdue |

## Критерии приёмки
1. Каждое действие из таблицы пишет ровно одно событие с нужными props.
2. Откат транзакции действия → события нет.
3. В props нет строк с текстом пунктов, имён, e-mail и комментариев.
4. Вызовы LLM в analytics_events не пишутся (они в llm_calls).
5. suggestion_added / suggestion_rejected — этап 3, сейчас не нужны.
