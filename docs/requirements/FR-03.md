# FR-03. Восстановление пароля

Приоритет: **Must** · Этап: **2, делается последней перед пилотом** (решение 23.10) · Модуль: аккаунт и серии

## Требование (SRS v3)
Восстановление пароля по ссылке из письма; ссылка действует 1 час и один раз.

## Критерии приёмки
1. `POST /auth/password-reset` с e-mail существующего ведущего → уходит письмо со ссылкой сброса.
2. `POST /auth/password-reset/confirm` с действующим токеном и новым паролем → пароль сменён (Argon2id), вход новым паролем работает, старым — 401.
3. Повторное использование того же токена → отказ (ссылка одноразовая).
4. Токен старше 1 часа → отказ.
5. Код ошибки для истёкшего или использованного токена — 410 `LINK_EXPIRED` (решение OQ-06).
6. Токен не пишется в логи (NFR-13).

## Правила и данные
- Тип письма и хранение токена сброса в модели данных не описаны — OQ-11.
- Токены ссылок в системе: 32 байта из криптостойкого генератора, base64url; в базе только SHA-256, сравнение за постоянное время (правило для ссылок исполнителя, предлагается взять и здесь).
