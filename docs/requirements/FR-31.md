# FR-31. Страница по ссылке и действия исполнителя

Приоритет: **Must** · Этап: **1** · Модуль: подтверждение по ссылке

## Требование (SRS v3)
Страница по ссылке: пункты получателя с этой встречи (что, срок, «готово», ведущий, название серии). Кнопки зависят от статуса: у pending — «Принимаю», «Нужен другой срок», «Это не моё»; у accepted — «Сделано», «Нужен другой срок», «Это не моё». Комментарий к «Это не моё» пишется в item_comments (BR-19).

## Критерии приёмки
1. `GET /p/{token}` без входа → только пункты получателя этой встречи: что, срок, «готово», ведущий, серия (AC-3.2). Формат — JSON для страницы SPA (OQ-01).
2. Чужие пункты и пункты, переназначенные с него, не показываются; `cancelled` — со статусом «снят» без кнопок.
3. Истёкшая или отозванная ссылка → 410 `LINK_EXPIRED`, в ответе только имя ведущего, без данных пунктов (AC-3.8).
4. `POST …/items/{id}/accept` у pending → `accepted`, `accepted_at`; CONFIRM_REPEAT отменяется (AC-3.4).
5. `POST …/reschedule` с датой у pending/accepted → `accepted`, новый due_date, `reschedule_count + 1`, `accepted_at` если пусто; HOST_RESPONSE; DUE_TOMORROW перепланируется; срок ссылки пересчитывается.
6. Дата раньше сегодня по поясу серии → 422 `DUE_IN_PAST`; позже исходного срока + 60 дней → 422 `DUE_TOO_LATE` (BR-6, AC-3.5).
7. `POST …/decline` у pending/accepted → `disputed`; комментарий необязателен, до 500 символов, в `item_comments` (kind = not_mine); 501 символ → 422; HOST_RESPONSE (AC-3.6).
8. `POST …/done` у accepted → `done`, `done_at`, `done_by = assignee`; напоминание отменяется; у pending → 409 `INVALID_TRANSITION`.
9. Действие над пунктом не из своей ссылки → 403 `NOT_YOUR_ITEM`; недопустимый переход → 409 `INVALID_TRANSITION`.
10. Ответ пишет `link_answered` (answer, hours_since_sent); открытие — `link_opened` (notification_type).
11. Заголовки `Referrer-Policy: no-referrer`, `X-Robots-Tag: noindex`; сторонних скриптов нет.
12. Больше 30 запросов в минуту с одного IP к `/p` → 429 (NFR-10).

## Правила и данные
- **BR-6.** Новый срок от исполнителя — не раньше сегодняшнего дня по поясу серии и не позже исходного срока + 60 дней. Смена срока исполнителем считается принятием пункта; ведущему подтверждать не нужно.
- **BR-19.** item_events только на вставку; в data только id, статусы и даты. Свободный текст — в item_comments.
- Кнопки у disputed и done, запись на GET — OQ-14.
