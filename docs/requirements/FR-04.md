# FR-04. Создание серии

Приоритет: **Must** · Этап: **1** · Модуль: аккаунт и серии

## Требование (SRS v3)
Создание серии: название, часовой пояс, плановая длительность (15–240 минут), режим сбора.

## Критерии приёмки
1. `POST /series` с title, timezone, planned_duration_min = 60 → 201, серия со `status = active`, `capture_mode = manual` по умолчанию.
2. planned_duration_min = 15 и = 240 → принимается; 14 и 241 → 422 `VALIDATION_ERROR`.
3. title длиннее 200 символов или пустой → 422 `VALIDATION_ERROR`.
4. timezone не из базы IANA (например `Mars/Base`) → 422 `VALIDATION_ERROR`.
5. `GET /series` возвращает только серии текущего ведущего (`owner_user_id`).
6. `GET /series/{id}` и `PATCH /series/{id}` для серии другого ведущего → 404 `NOT_FOUND` (не 403, NFR-09).
7. `PATCH /series/{id}` меняет title, timezone, planned_duration_min с теми же проверками.
8. При создании пишется событие `series_created` с props `members_count`, `has_external`.
9. `capture_mode = audio` на этапах 1–2 — OQ-15.

## Правила и данные
- `series`: id, owner_user_id, title varchar(200), timezone, planned_duration_min smallint, capture_mode enum(manual, audio) = manual, status enum(active, archived), created_at. INDEX(owner_user_id, status).
- Часовой пояс серии задаёт «сегодня» для сроков, рабочие дни (BR-7) и расписание писем.
