# FR-14. Живая панель по WebSocket

Приоритет: **Must** · Этап: **1** · Модуль: панель встречи

## Требование (SRS v3)
Панель обновляется по WebSocket; после обрыва переподключается и догружает изменения по номеру версии.

## Критерии приёмки
1. `WS /ws/meetings/{id}` с cookie ведущего — владельца серии → соединение открыто.
2. Без сессии или для встречи другого ведущего → соединение отклонено.
3. Добавление пункта → событие `item.created`; правка → `item.updated`; пересчёт пробелов → `gaps.updated`; открытие закрытия → `closure.opened`.
4. Обрыв сети → панель переподключается не позже 5 с и догружает пропущенные изменения (NFR-05); после догрузки панель совпадает с данными сервера.
5. Изменение, сделанное во время обрыва (например, из второй вкладки), видно после переподключения.
6. Счётчик пробелов обновляется не позже 1 с после изменения (AC-1.3).

## Правила и данные
- `items.version` — номер версии пункта, по нему клиент понимает, что пропустил.
- Как именно догружать (какой запрос) и событие удаления пункта — OQ-07.
