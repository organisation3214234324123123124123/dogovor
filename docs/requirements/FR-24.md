# FR-24. «Не пробел»

Приоритет: **Must** · Этап: **1** · Модуль: пробелы и закрытие

## Требование (SRS v3)
«Не пробел» скрывает подсказку (dismissed_at); та же подсказка по этому пункту больше не показывается.

## Критерии приёмки
1. `POST /items/{id}/gaps/{gapId}/dismiss` → у пробела ставится `dismissed_at`, счётчик уменьшается, приходит `gaps.updated`.
2. После следующей правки пункта пробел того же типа по этому пункту не появляется снова (AC-1.4).
3. Пробел того же типа у другого пункта показывается как обычно.
4. Пишется событие `gap_dismissed` с props `type`, `source`.
5. Повторный dismiss того же пробела → без второго события `gap_dismissed` (ответ API — OQ-06).
6. Пробел или пункт другого ведущего → 404 `NOT_FOUND`.
7. Отклонённый пробел не считается открытым для BR-3, но условие «есть due_date» BR-3 продолжает действовать.

## Правила и данные
- Открытый пробел: resolved_at IS NULL AND dismissed_at IS NULL.
- Метрика: доля отклонённых подсказок = gap_dismissed ÷ показанные подсказки (больше 30% — тревога).
