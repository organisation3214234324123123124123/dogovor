# Требования

ТЗ (SRS v3, согласовано 22–23.10) — рабочий документ аналитиков. Здесь оно разрезано на файлы для этапов 1–2 (MVP).

- `FR-xx.md` — одно требование: текст из SRS, критерии приёмки списком (для тестов), правила и поля, ссылки. 36 Must и 6 Should.
- [BR.md](BR.md) — бизнес-правила; [NFR.md](NFR.md) — нефункциональные, влияющие на код.
- [data-model.md](data-model.md) — таблицы, статусы пункта и переходы, письма; [api.md](api.md) — соглашения, ошибки, ручки.
- [open-questions.md](open-questions.md) — дыры и противоречия с предложенными решениями (OQ-xx); решения предложены, аналитики их ещё не подтвердили.
- [traceability.md](traceability.md) — FR → код → тесты → статус.

Правила: тесты пишутся из критериев приёмки FR, коммит называет закрываемые FR. Требование меняется сначала в Google Docs, затем здесь отдельным коммитом. Ссылка на OQ-xx в FR значит: работаем по предложенному решению, пока аналитики не подтвердили или не изменили решение.
