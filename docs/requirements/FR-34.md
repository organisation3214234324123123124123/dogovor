# FR-34. Письмо ведущему HOST_RESPONSE

Приоритет: **Must** · Этап: **1** · Модуль: подтверждение по ссылке

## Требование (SRS v3)
«Нужен другой срок» или «Это не моё» — ведущий получает письмо HOST_RESPONSE сразу.

## Критерии приёмки
1. Исполнитель нажал «Нужен другой срок» → ведущему HOST_RESPONSE не позже 5 минут: кто ответил и новый срок (AC-3.5).
2. «Это не моё» → HOST_RESPONSE: кто ответил, «не моё» и комментарий, если есть (AC-3.6).
3. В письме кнопка, которая открывает карточку пункта в кабинете (FR-45).
4. «Принимаю» и «Сделано» HOST_RESPONSE не создают.
5. Каждый ответ — своё письмо: dedupe_key `item:HOST_RESPONSE:event_id`.
6. HOST_RESPONSE не входит в лимит 3 письма в неделю (BR-11).
7. Получатель — `recipient_user_id` (ведущий), `recipient_person_id` пусто.

## Правила и данные
- **BR-6.** Смена срока исполнителем считается принятием пункта; ведущий получает HOST_RESPONSE и видит смену в сверке. Подтверждать новый срок не нужно; если не согласен — переносит или переназначает.
- NFR-06: немедленные письма (SUMMARY, HOST_RESPONSE) уходят не позже 5 минут; падение воркера не теряет письма, два воркера не шлют одно письмо.
