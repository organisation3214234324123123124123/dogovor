# FR-35. Ссылка у каждого исполнителя, включая согласованные пункты

Приоритет: **Must** · Этап: **1** · Модуль: подтверждение по ссылке · Решение 23.10

## Требование (SRS v3)
Ссылка в итоговом письме есть у каждого исполнителя, включая пункты, согласованные на встрече. Отметка «Согласовано на встрече» — фиксация ведущим устного ответа; исполнитель может оспорить её или сменить срок.

## Критерии приёмки
1. Пункт согласован на встрече и разослан → `accepted`; SUMMARY исполнителю без просьбы подтвердить, но со ссылкой с кнопками «Нужен другой срок» и «Это не моё» (AC-2.3).
2. По этой ссылке исполнитель жмёт «Это не моё» → `disputed`, ведущему HOST_RESPONSE (AC-2.6); случай считается в метрике «Оспорено после согласования».
3. По этой ссылке «Нужен другой срок» → новый срок, `accepted` (BR-6).
4. Участник встречи без пунктов получает SUMMARY без ссылки.
5. У каждого своего пункта в SUMMARY: для pending — «Принимаю», «Нужен другой срок», «Это не моё»; для согласованных — «Нужен другой срок», «Это не моё».

## Правила и данные
- SUMMARY: dedupe_key `meeting:SUMMARY:person`; решения встречи, свои пункты получателя сверху.
- Почему в SUMMARY у принятого нет «Сделано», а на странице есть — OQ-04.
