# FR-29. Встреча после рассылки

Приоритет: **Must** · Этап: **1** · Модуль: пробелы и закрытие

## Требование (SRS v3)
После рассылки встреча в статусе sent: пункты нельзя удалить, только снять; правка полей — по FR-16.

## Критерии приёмки
1. После `POST /meetings/{id}/send` у встречи `status = sent`.
2. `DELETE /items/{id}` у разосланного пункта → 409 `INVALID_TRANSITION`.
3. «Снять» (`POST /items/{id}/actions` `cancel`) из pending, accepted, disputed → `cancelled`, `cancelled_at`; напоминание отменяется; писем нет; по ссылке исполнитель видит «снят».
4. «Снять» у done или cancelled → 409 `INVALID_TRANSITION`.
5. Правка «что», срока, «готово» — по FR-16; исполнитель — только «Переназначить».
6. Добавление пункта после рассылки — OQ-02.

## Правила и данные
- Переход: pending, accepted, disputed → cancelled | «Снять» | Ведущий | cancelled_at; напоминание отменяется; писем нет.
