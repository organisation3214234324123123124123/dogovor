# FR-13. Правка полей пункта в панели

Приоритет: **Must** · Этап: **1** · Модуль: панель встречи

## Требование (SRS v3)
Правка любого поля пункта в панели: исполнитель из состава встречи, срок — календарь.

## Критерии приёмки
1. `PATCH /items/{id}` с `If-Match: 1` и новым `what` у пункта в draft → 200, `version = 2`, `what` в `manual_fields`.
2. Устаревший `If-Match` → 409 `VERSION_CONFLICT`, пункт не изменён.
3. Исполнитель не из участников серии → 422 `NOT_A_PARTICIPANT` (BR-1).
4. due_date раньше сегодняшнего дня по поясу серии → 422 `DUE_IN_PAST` (BR-2).
5. what длиннее 500, done_criteria длиннее 500, due_text длиннее 100 → 422 `VALIDATION_ERROR`.
6. После правки пробелы пересчитываются (FR-20); в панель приходят `item.updated` и `gaps.updated`.
7. Смена даты в draft не увеличивает `reschedule_count` (AC-2.4).
8. Правка пункта после рассылки идёт по FR-16 (исполнитель — только через «Переназначить»).
9. Пункт другого ведущего → 404 `NOT_FOUND`.

## Правила и данные
- **BR-1.** Исполнителем может быть только участник серии. Нового человека ведущий сначала добавляет в состав — прямо из панели.
- **BR-2.** Срок — дата не раньше сегодняшней по поясу серии.
- `items.version int = 1` — оптимистичная блокировка; изменение пункта передаёт `If-Match: <version>`.
- `items.manual_fields text[]` — поля, поправленные ведущим (их не трогает LLM, BR-15).
