# FR-27. Контроль повестки в режиме закрытия

Приоритет: **Should** · Этап: **2** · Модуль: пробелы и закрытие

## Требование (SRS v3)
В режиме закрытия — пункты повестки без единого связанного решения; связь ставит ведущий или предлагает LLM. Действия: «Обсудили», «Перенести на следующую».

## Критерии приёмки
1. В режиме закрытия пункт повестки без единого `items.agenda_item_id` на него показан как непокрытый.
2. Ведущий связывает решение с пунктом повестки → пункт повестки больше не непокрытый.
3. При открытии закрытия один запрос к LLM сопоставляет повестку и решения и возвращает пары `{agenda_item_id, item_id}`; пары с id не из этой встречи отбрасываются.
4. «Обсудили» → `agenda_items.status = covered`; «Перенести на следующую» → `moved` (копируется в следующую встречу, FR-08).
5. Пишется `agenda_item_uncovered` с props `position`, `resolution` (covered, moved).
6. LLM недоступна → непокрытые пункты считаются по связям, поставленным ведущим.

## Правила и данные
- `agenda_items.status enum(open, covered, moved)`; `items.agenda_item_id` — необязательная связь.
