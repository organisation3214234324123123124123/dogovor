# FR-22. Режим закрытия

Приоритет: **Must** · Этап: **1** · Модуль: пробелы и закрытие

## Требование (SRS v3)
«Закрыть встречу» переводит панель в режим закрытия: пункты с открытыми пробелами сверху, у каждого вопрос, счётчик оставшихся пробелов.

## Критерии приёмки
1. `POST /meetings/{id}/closure` у встречи в `live` → `status = closing`, `closure_opened_at` заполнен, `closure_trigger = button`.
2. В панель приходит событие `closure.opened`.
3. Пункт без исполнителя и срока стоит в верхней группе с метками «нет исполнителя», «нет срока», «размыто» и одним готовым вопросом до 120 символов (AC-1.1).
4. Ниже — пункты без открытых пробелов; виден счётчик «осталось N пробелов».
5. Закрытие пробела → счётчик уменьшается не позже 1 с (AC-1.3).
6. Все пробелы закрыты или отклонены → «Всё ясно» и кнопка «Разослать» (AC-1.6).
7. LLM недоступна → пробелы по правилам всё равно показаны (AC-1.8).
8. Подсказки видит только ведущий (AC-1.5).
9. Встреча не в `live` → 409 `MEETING_NOT_LIVE`; встреча другого ведущего → 404.
10. Пишется событие `closure_opened` с props `trigger` (button), `minutes_to_planned_end`.
11. В режиме закрытия по-прежнему можно добавлять и править пункты.

## Правила и данные
- `meetings.status enum(planned, live, closing, sent)`, `closure_opened_at`, `closure_trigger enum(button, timer)`.
