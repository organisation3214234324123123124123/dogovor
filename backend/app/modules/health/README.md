# health

Проба живости: `GET /api/v1/health` (NFR-11), схема `Health`. В ответе:

- `status` (ok, degraded, down), `db`, `version` (`APP_VERSION`, чтобы клиент мог сверить свою);
- `email_queue`: сколько писем в очереди, сколько упало за сутки, возраст самого старого;
- `llm`: доступен ли реальный клиент (при пустом ключе работает заглушка);
- `worker_last_run_at`: время последнего отправленного письма, null, если писем не было.

Сбой БД не роняет ручку: ответ 503 с `db: down`. Redis не проверяется.
