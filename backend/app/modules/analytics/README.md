# analytics

События продукта без персональных данных (`analytics_events`) и их выгрузка.

Единственная ручка — `GET /admin/export/events.csv?from&to` (FR-51). Запись событий (FR-50) — функция сервиса `track`, ручки у неё нет. Служебные ручки `/admin/*` принимают только заголовок `X-Admin-Token` (пусто — 403 `ADMIN_DISABLED`); сессия ведущего не подходит.

Раз в сутки Beat запускает `cleanup_retention`: удаляет или обезличивает данные старше сроков хранения (BR-20); сроки и порядок — в [docs/decisions.md](../../../../docs/decisions.md). Обезличивание участника по запросу (FR-52) живёт в модуле `series`.
