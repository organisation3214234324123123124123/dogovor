# gaps

Пробелы пункта (FR-20, FR-21): `no_assignee`, `no_due`, `due_vague`, `due_past`, `vague_action`.
Своих ручек нет: открытые пробелы приходят в `ItemRead.gaps`, «Не пробел» — `POST /items/{id}/gaps/{gapId}/dismiss` в модуле items (FR-24).

- `rules` — чистые функции поиска пробелов и стандартного вопроса.
- `service.recalc` вызывается при каждом изменении пункта: закрывает ушедшие пробелы, открывает вернувшиеся, отклонённый тип не открывает.
- `service.dismiss` помечает пробел отклонённым.

Пробелы, найденные LLM, правила не закрывают.
